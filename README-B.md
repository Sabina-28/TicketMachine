Ticket Machine – Member B

Admin Features Implemented (Member B)

The file AdminMain.kt contains the administrator console system.

The admin menu includes:
- View all destinations - Displays the current destination list and their ticket prices.
- Add destination - Allows admin users to add new destinations into the repository.
- Edit destination - Modify existing destination names or prices.
- Change ALL ticket prices by a factor - Applies a multiplier to every ticket price in the system.
- Exit - Leaves the admin interface.

Project Structure
- AdminMain.kt	- Implements admin menu and system-management functions
- Destination.kt -	Stores destination properties
- DestinationService.kt -	Handles CRUD operations for destinations
- Ticket.kt -	Represents a ticket object

How to Run the Admin System:
- Open the project in IntelliJ IDEA.
- Navigate to src → AdminMain.kt
- Click Run to start the admin console.
- Follow the on-screen menu to manage destinations and pricing.
